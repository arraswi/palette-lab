# Palette Lab

Ferramenta visual para gerar paletas de cores, ajustar tons, travar amostras e exportar variáveis CSS ou JSON.

## Recursos

- Harmonias análoga, complementar e monocromática.
- Edição direta de cada amostra.
- Trava de cores para preservá-las ao gerar novas combinações.
- Cópia de HEX e variáveis CSS.
- Exportação da paleta em JSON.
- Biblioteca local das últimas seis paletas salvas.
- Atalho de espaço para gerar uma nova combinação.

## Executar

Requisitos: Node.js 20.19 ou superior.

    npm install
    npm run dev

## Tecnologias

Vue 3 · TypeScript · Vite · CSS
